# Dock Fit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The dock always fits its screen. It gives room back in a fixed
cascade: shorter labels, folded labels, tighter spacing, smaller icons.
As a last resort it moves items from the end of the row into a "»"
overflow popup.

**Architecture:**

- A pure JS planner (`DockFit.js`) turns the row's items and sizes into
  one cascade state.
- A host component (`components/DockFitHost.qml`) gathers the inputs from
  the dock, recomputes the plan deferred, and owns the "»" popup's life
  and window.
- `Dock.qml` only reads a few effective values (`iconSize`, `gapWidth`,
  `sectionGap`). The row components hide overflowed items and fold
  labels from the plan.

**Tech Stack:** Quickshell 0.3.1 / QML (Qt 6.12), plain JS modules loaded
in node `vm` contexts for unit tests, Python static checks.

**Spec:** `docs/superpowers/specs/2026-10-11-dock-fit-design.md`

## Global Constraints

- CI line ceilings, which only go down (`tests/static/structure-check.py`):
  `Dock.qml` 2412, `DockModel.js` 1326. Run the check before every
  commit; new logic goes into `components/` or `components/logic/`.
- JS modules hold no Qt globals and are testable in a node `vm` context
  (like `DockLayout.js`).
- Deferred work goes through a child `Timer` with interval 0, never
  `Qt.callLater`, whenever the call reads JS imports (#61 lesson).
- `LABEL_MAX_WIDTH_MIN` is 80. The icon floor is `max(24, iconSize / 2)`,
  where iconSize is the configured or auto size.
- The overflow order runs from the very end of the row: drives, folders
  and buttons, running apps, tiles, pinned apps and groups, then the
  Omarchy button. A group is one item.
- The "»" popup: click and right click only, no drag.
- There is no setting. Steps 1 and 2 are skipped unless labels are
  `always`.
- Motion follows `Dock.motion` (Full / Reduced / Off).
- Code, comments and commits are in English, with no AI attribution. One
  topic per commit, and the body explains why.
- The live checkout is the running desktop. Work happens in the worktree
  `~/.local/share/omadock-wt/fit` on branch `feat/dock-fit`, which is
  merged into `priard` only after a `git merge-tree --write-tree` check
  of its exit status.

## Review Focus

1. **A plan change while a popup is open.** A running app closes while
   its folder stack is open; the stack must stay put unless its anchor
   item overflowed. The test goes in Task 7.
2. **A long app name with labels at Always and a dock that nearly
   fits.** Opening and closing one window at the edge must not flip the
   fold on and off (hysteresis). The test goes in Task 1.
3. **A drag across the dock while the plan would change.** The drop
   zones must not jump. The plan freezes during a drag (Task 7).
4. **Labels set to plates with side marks.** Folded tiles keep their
   plate, and the planner's predicted width must not be narrower than
   what is drawn (plate grid ceil plus one device pixel). The test goes
   in Task 1.
5. **Both sides with overflow.** The spread gap must never be counted
   as room (the host's `room()` is the stretched card's inner width; the
   gap only takes what is left), and "»" ends the right group. The live
   check goes in Task 4: run it once with Both sides on.

### Task 1: The planner `DockFit.js`

**Files:**
- Create: `DockFit.js`
- Test: `tests/unit/fit.test.mjs`

**Interfaces:**
- Produces:
  - `plan(input, prev) -> { level, labelMax, fold, t, gap, iconSize, overflowFrom, width }`.
    - `fold` is one of `"none"`, `"closedPinned"`, `"apps"`, `"all"`.
    - `t` (0..1) is the spacing fraction; `gap` is the item gap in px.
    - `overflowFrom` is an index into `input.items`, or -1.
    - `width` is the predicted row width.
  - `rowWidth(input, cand) -> number`.
  - `FOLDS = ["none", "closedPinned", "apps", "all"]`.
- Input shape:
  ```
  {
    available,      // px of room for the row
    items: [{ id, kind, pinned, running, label }],
                    // kind: button|app|group|tile|folder|drive|separator
                    // label: null | { text, inner, outer, folded, asleep }
                    //   text   = full name advance width
                    //   inner  = room the name's budget spends besides the text
                    //   outer  = room the open label adds besides the text
                    //   folded = room a folded label keeps (side-mark column)
                    //   asleep = folded already by "Pinned apps: When running"
    labels,         // true when labels are "always" (they take room)
    labelMax,       // configured max width
    labelMin,       // 80
    iconSize, floor,
    slotPad,        // iconSlot = iconSize + slotPad
    gapMax, gapMin,
    sepMax, sepMin, // separator width at t = 1 and t = 0
    tileFactor,     // 1.5
    wave,           // true for the Wave hover effect
    dpr,            // plate grid scale, 0 when not plates
    margin          // hysteresis margin, px
  }
  ```

```js
// DockFit.js
// The dock's fit to its screen (docs/superpowers/specs/2026-10-11-dock-fit-design.md):
// when the row would be wider than its room, it gives width back in a fixed
// order - shorter labels, folded labels, tighter spacing, smaller icons -
// and only then moves items from the end of the row into "»". Plain JS with
// no Qt globals, so the node tests run it in a vm context like DockLayout.js.
//
// Nothing in the input depends on the plan (label widths are the full,
// unshortened names; counts are the dock's own lists), so the dock cannot
// chase its own result.

var FOLDS = ["none", "closedPinned", "apps", "all"]
// Wave magnification: the hovered slot grows by 0.4 and its neighbours by
// the cosine weights over +-2.2 slots, about 2.18 slots' worth in all.
var WAVE_GROWTH = 0.4 * 2.18

function _snapDown(v, dpr) { return dpr > 0 ? Math.floor(v * dpr + 1e-9) / dpr : v }
// The smallest whole logical size from n up on whole device pixels (as
// DockLabels.gridInt).
function _gridInt(n, dpr) {
  if (!(dpr > 0)) return Math.round(n)
  for (var k = 0; k < 8; k++) {
    var m = Math.round(n) + k
    if (Math.abs(m * dpr - Math.round(m * dpr)) < 1e-9) return m
  }
  return Math.round(n)
}

function _slot(input, iconSize) { return _gridInt(iconSize + input.slotPad, input.dpr) }
function _gap(input, t) { return _snapDown(input.gapMin + t * (input.gapMax - input.gapMin), input.dpr) }

function _folded(item, fold) {
  var l = item.label
  if (!l) return true
  if (l.asleep || fold === "all") return true
  if (fold === "apps") return item.kind === "app"
  if (fold === "closedPinned") return item.kind === "app" && !!item.pinned && !item.running
  return false
}

function _labelWidth(input, item, cand) {
  var l = item.label
  if (!input.labels || !l) return 0
  // A plate row's tile lands on the device grid: one device pixel more,
  // so the prediction is never narrower than what is drawn.
  var grid = input.dpr > 0 ? 1 / input.dpr : 0
  if (_folded(item, cand.fold)) return l.folded > 0 ? l.folded + grid : 0
  return Math.min(l.text, Math.max(0, cand.labelMax - l.inner)) + l.outer + grid
}

// The items kept in the row for a cut: separators that no longer stand
// between two kept items go too.
function _kept(items, cut) {
  var n = cut < 0 ? items.length : cut
  var out = []
  for (var i = 0; i < n; i++) out.push(items[i])
  while (out.length > 0 && out[out.length - 1].kind === "separator") out.pop()
  var clean = []
  for (var j = 0; j < out.length; j++) {
    if (out[j].kind === "separator" && (clean.length === 0 || clean[clean.length - 1].kind === "separator")) continue
    clean.push(out[j])
  }
  return clean
}

function rowWidth(input, cand) {
  var slot = _slot(input, cand.iconSize)
  var gap = _gap(input, cand.t)
  var sep = input.sepMin + cand.t * (input.sepMax - input.sepMin)
  var kept = _kept(input.items || [], cand.overflowFrom)
  var w = 0
  var count = kept.length
  for (var i = 0; i < kept.length; i++) {
    var it = kept[i]
    if (it.kind === "separator") w += sep
    else if (it.kind === "tile") w += Math.round(slot * input.tileFactor)
    else w += slot + _labelWidth(input, it, cand)
  }
  if (cand.overflowFrom >= 0) { w += slot; count++ }
  w += Math.max(0, count - 1) * gap
  if (input.wave && count > 0) w += Math.ceil(slot * WAVE_GROWTH)
  return w
}

function _fits(input, cand, room) { return rowWidth(input, cand) <= room }

// Largest integer in [lo, hi] for which ok(v) holds, given ok is monotone
// (true up to some value). lo - 1 when none.
function _maxInt(lo, hi, ok) {
  if (!ok(lo)) return lo - 1
  while (lo < hi) {
    var mid = Math.ceil((lo + hi) / 2)
    if (ok(mid)) lo = mid
    else hi = mid - 1
  }
  return lo
}

function _solve(input, room) {
  var base = { labelMax: input.labelMax, fold: "none", t: 1, iconSize: input.iconSize, overflowFrom: -1 }
  var c = Object.assign({}, base)
  if (_fits(input, c, room)) return _done(input, c, 0)
  // 1. shorter labels, then 2. folds, each with the most label room left.
  if (input.labels) {
    for (var f = 0; f < FOLDS.length - 1; f++) {
      var fold = FOLDS[f]
      var best = _maxInt(input.labelMin, input.labelMax, function(L) {
        return _fits(input, { labelMax: L, fold: fold, t: 1, iconSize: input.iconSize, overflowFrom: -1 }, room)
      })
      if (best >= input.labelMin) {
        c = { labelMax: best, fold: fold, t: 1, iconSize: input.iconSize, overflowFrom: -1 }
        var span = Math.max(1, input.labelMax - input.labelMin)
        var level = f === 0 ? 1 + (input.labelMax - best) / span : 2 + f / 3
        return _done(input, c, level)
      }
    }
  }
  var fold2 = input.labels ? "all" : "none"
  var lmax = input.labels ? input.labelMin : input.labelMax
  if (input.labels && _fits(input, { labelMax: lmax, fold: "all", t: 1, iconSize: input.iconSize, overflowFrom: -1 }, room))
    return _done(input, { labelMax: lmax, fold: "all", t: 1, iconSize: input.iconSize, overflowFrom: -1 }, 3)
  // 3. spacing: bisect t.
  if (_fits(input, { labelMax: lmax, fold: fold2, t: 0, iconSize: input.iconSize, overflowFrom: -1 }, room)) {
    var lo = 0, hi = 1
    for (var k = 0; k < 24; k++) {
      var mid = (lo + hi) / 2
      if (_fits(input, { labelMax: lmax, fold: fold2, t: mid, iconSize: input.iconSize, overflowFrom: -1 }, room)) lo = mid
      else hi = mid
    }
    return _done(input, { labelMax: lmax, fold: fold2, t: lo, iconSize: input.iconSize, overflowFrom: -1 }, 3 + (1 - lo))
  }
  // 4. icons down to the floor.
  var size = _maxInt(input.floor, input.iconSize, function(s) {
    return _fits(input, { labelMax: lmax, fold: fold2, t: 0, iconSize: s, overflowFrom: -1 }, room)
  })
  if (size >= input.floor) {
    var range = Math.max(1, input.iconSize - input.floor)
    return _done(input, { labelMax: lmax, fold: fold2, t: 0, iconSize: size, overflowFrom: -1 }, 4 + (input.iconSize - size) / range)
  }
  // 5. overflow from the end: the most items kept that still fit.
  var n = (input.items || []).length
  var cut = _maxInt(0, n - 1, function(k) {
    return _fits(input, { labelMax: lmax, fold: fold2, t: 0, iconSize: input.floor, overflowFrom: k }, room)
  })
  if (cut < 0) cut = 0
  // A cut right after a separator draws the same row; keep the separator
  // with the hidden part so the cut always follows a real item.
  var all = input.items || []
  while (cut > 0 && all[cut - 1].kind === "separator") cut--
  return _done(input, { labelMax: lmax, fold: fold2, t: 0, iconSize: input.floor, overflowFrom: cut }, 5 + (n - cut) / Math.max(1, n))
}

function _done(input, c, level) {
  return { level: level, labelMax: c.labelMax, fold: c.fold, t: c.t, gap: _gap(input, c.t),
    iconSize: c.iconSize, overflowFrom: c.overflowFrom, width: rowWidth(input, c) }
}

// The plan for this input. prev: the plan in force; a gentler plan than it
// is taken only when it also fits with input.margin to spare, so a window
// coming and going right at the edge does not flip the dock back and forth.
function plan(input, prev) {
  var room = Math.max(0, Number(input.available) || 0)
  var next = _solve(input, room)
  if (prev && next.level < prev.level) {
    var held = _solve(input, Math.max(0, room - (input.margin || 0)))
    if (held.level > next.level) return held.level >= prev.level ? Object.assign({}, prev, _done(input, prev, prev.level)) : held
  }
  return next
}
```

Note on the hysteresis branch: `_done(input, prev, prev.level)` recomputes `gap` and `width` for the current input while keeping the old decisions. `prev` carries `labelMax`, `fold`, `t`, `iconSize` and `overflowFrom`, which is exactly what `_done` reads.

// DockLabels.js, after withExtra
// Each label's full, unshortened width for the dock's fit planner
// (DockFit.js): text is the name's advance, inner what the max-width budget
// spends besides it, outer what the open label adds besides it, folded the
// room a folded label keeps. Same ownership rule as withExtra; unchanged
// input returns the same object.
function withNatural(map, slot, owner, entry) {
  var cur = map ? map[slot] : undefined
  if (!entry) {
    if (!cur || cur.owner !== owner) return map
    var cleared = {}
    for (var c in map) if (Number(c) !== Number(slot)) cleared[c] = map[c]
    return cleared
  }
  var e = { owner: owner, text: Math.ceil(entry.text || 0), inner: Math.ceil(entry.inner || 0),
    outer: Math.ceil(entry.outer || 0), folded: Math.ceil(entry.folded || 0) }
  if (cur && cur.owner === owner && cur.text === e.text && cur.inner === e.inner && cur.outer === e.outer && cur.folded === e.folded) return map
  var next = {}
  for (var k in map) next[k] = map[k]
  next[slot] = e
  return next
}

import qs.Commons
import "../DockFit.js" as DockFit

// The dock's fit to its screen (DockFit.js): gathers the row's items and
// sizes from the dock, keeps the plan, and recomputes it a turn later
// (child Timer: a burst of changes gives one plan). The overflow popup's
// life and window live here too (Task 5), so Dock.qml stays under its cap.
Item {
  id: host
  property var dockRoot: null
  readonly property var root: dockRoot
  width: 0
  height: 0

  // Temporary (live checks): a room in px that replaces the measured one.
  property real availableOverride: -1

  property var plan: ({ level: 0, labelMax: 140, fold: "none", t: 1, gap: 0, iconSize: 0, overflowFrom: -1, width: 0 })
  property var hidden: ({})
  property var shown: ({ button: 1, pinned: 0, tiles: 0, running: 0, folders: 0, drives: 0 })
  property var hiddenItems: []
  // Frozen while something is dragged on the dock (Task 7).
  readonly property bool frozen: false

  readonly property real configuredGap: root ? (root.labelPlates ? root.plateSpacing.gap : Style.space(root.itemSpacing)) : 0

  function room() {
    if (host.availableOverride >= 0) return host.availableOverride
    var card = root ? root.dockCardComp : null
    var win = root ? root.dockWindowRef : null
    if (!card || !win) return 1e9
    var insets = card.dockCard.contentLeftInset + card.dockCard.contentRightInset
    if (card.stretch) return card.stretch.width - insets
    return win.width - 4 * Style.gapsOut - insets
  }

  function labelFor(slot, item) {
    var n = root.labelNaturals[slot]
    if (!n) return null
    return { text: n.text, inner: n.inner, outer: n.outer, folded: n.folded,
      asleep: !!(item && item.asleep) }
  }

  // The row in order, with the label slots the delegates use.
  function items() {
    var out = []
    var slot = 0
    if (root.showAppsButton) { out.push({ id: "button", kind: "button", label: null }); slot++ }
    var pins = root.pinnedRow || []
    for (var i = 0; i < pins.length; i++) {
      var p = pins[i]
      var isGroup = !!p.group
      var e = p.entry || {}
      var asleep = !isGroup && root.labelPinned === "running" && !e.running
      out.push({ id: "pin:" + root.pinnedRowKey(p), kind: isGroup ? "group" : "app", pinned: true,
        running: !!e.running, label: host.labelFor(slot, { asleep: asleep }) })
      slot++
    }
    var tiles = root.tileModel || []
    if (tiles.length > 0 && root.hasLeftTileSeparator) out.push({ id: "sep:pinTiles", kind: "separator" })
    for (var t = 0; t < tiles.length; t++) out.push({ id: "tile:" + DockKeys.tileKey(tiles[t]), kind: "tile" })
    if (root.hasSeparator) out.push({ id: "sep:run", kind: "separator" })
    var run = root.runningSection || []
    for (var r = 0; r < run.length; r++) {
      var re = run[r]
      if (root.showMinimizedTiles && DockModel.allWindowsMinimized(re.windowList, root.liveWsNameOf, root.minimizedWorkspace)) continue
      out.push({ id: "run:" + re.appId, kind: "app", pinned: false, running: true, label: host.labelFor(slot, null) })
      slot++
    }
    var folders = (root.pinnedFolders || []).concat(root.pinnedButtons || [])
    if (root.hasFolderSeparator) out.push({ id: "sep:folders", kind: "separator" })
    for (var f = 0; f < folders.length; f++) {
      out.push({ id: "folder:" + DockKeys.folderKey(folders[f]), kind: "folder", pinned: true, label: host.labelFor(slot, null) })
      slot++
    }
    var drives = (root.showRemovableDrives && root.mountedDrives) ? root.mountedDrives : []
    if (root.hasDriveSeparator) out.push({ id: "sep:drives", kind: "separator" })
    for (var d = 0; d < drives.length; d++) out.push({ id: "drive:" + DockKeys.driveKey(drives[d]), kind: "drive", label: null })
    return out
  }

  function recompute() {
    if (!root || host.frozen) return
    var list = host.items()
    var input = {
      available: host.room(), items: list,
      labels: root.labelMode === "always", labelMax: root.labelMaxWidth, labelMin: 80,
      iconSize: root.baseIconSize, floor: Math.max(24, Math.round(root.baseIconSize / 2)),
      slotPad: Style.space(10), gapMax: host.configuredGap,
      gapMin: root.labelPlates ? Style.space(4) : 0,
      sepMax: root.separatorWidthAt(1), sepMin: root.separatorWidthAt(0),
      tileFactor: 1.5, wave: root.waveHover, dpr: root.labelPlates ? root.outputScale : 0,
      margin: Style.space(8)
    }
    var next = DockFit.plan(input, host.plan.iconSize > 0 ? host.plan : null)
    var hid = {}
    var cut = next.overflowFrom
    var hiddenList = []
    if (cut >= 0) for (var i = cut; i < list.length; i++) if (list[i].kind !== "separator") { hid[list[i].id] = true; hiddenList.push(list[i].id) }
    var counts = { button: 0, pinned: 0, tiles: 0, running: 0, folders: 0, drives: 0 }
    for (var j = 0; j < list.length; j++) {
      var it = list[j]
      if (hid[it.id] || it.kind === "separator") continue
      var pre = it.id.split(":")[0]
      if (pre === "button") counts.button++
      else if (pre === "pin") counts.pinned++
      else if (pre === "tile") counts.tiles++
      else if (pre === "run") counts.running++
      else if (pre === "folder") counts.folders++
      else if (pre === "drive") counts.drives++
    }
    host.plan = next
    if (JSON.stringify(hid) !== JSON.stringify(host.hidden)) host.hidden = hid
    if (JSON.stringify(counts) !== JSON.stringify(host.shown)) host.shown = counts
    if (JSON.stringify(hiddenList) !== JSON.stringify(host.hiddenItems)) host.hiddenItems = hiddenList
  }

  Timer { id: later; interval: 0; onTriggered: host.recompute() }
  function schedule() { later.restart() }

  // Everything the input reads. Changes of the plan's own outputs (iconSize,
  // gapWidth, labelExtras) are deliberately not here.
  Connections {
    target: host.root
    function onPinnedRowChanged() { host.schedule() }
    function onRunningSectionChanged() { host.schedule() }
    function onTileModelChanged() { host.schedule() }
    function onPinnedFoldersChanged() { host.schedule() }
    function onPinnedButtonsChanged() { host.schedule() }
    function onMountedDrivesChanged() { host.schedule() }
    function onLabelNaturalsChanged() { host.schedule() }
    function onLabelModeChanged() { host.schedule() }
    function onLabelMaxWidthChanged() { host.schedule() }
    function onLabelPinnedChanged() { host.schedule() }
    function onBaseIconSizeChanged() { host.schedule() }
    function onItemSpacingChanged() { host.schedule() }
    function onSectionSpacingChanged() { host.schedule() }
    function onPlacementChanged() { host.schedule() }
    function onHoverEffectChanged() { host.schedule() }
    function onShowAppsButtonChanged() { host.schedule() }
    function onLabelBackgroundChanged() { host.schedule() }
  }
  Connections {
    target: host.root ? host.root.dockWindowRef : null
    function onWidthChanged() { host.schedule() }
  }
  onAvailableOverrideChanged: host.schedule()
  Component.onCompleted: host.schedule()
}

import Quickshell
import qs.Commons
import qs.Ui
import "../DockModel.js" as DockModel
import "../DockLabels.js" as DockLabels

// The items that did not fit (DockFit.js), in dock order, as an opened
// group shows its apps: icon, name, window marks. Click acts as on the
// dock, right click opens the item's own menu over its cell. No drag.
BorderSurface {
  id: pop
  property var rootRef: null
  readonly property var root: rootRef
  property var hostRef: null
  property var popupWindow: null

  // { id, kind, title, icon, data } per hidden item.
  readonly property var cells: {
    var out = []
    if (!root || !hostRef) return out
    var ids = hostRef.hiddenItems
    var card = root.dockCardComp
    for (var i = 0; i < ids.length; i++) {
      var id = ids[i]
      var sep = id.indexOf(":")
      var kind = sep < 0 ? id : id.slice(0, sep)
      var key = sep < 0 ? "" : id.slice(sep + 1)
      if (kind === "pin") {
        var p = root.pinnedRowByKey[key]
        if (!p) continue
        if (p.group) out.push({ id: id, kind: "group", title: p.group.name || "Group", icon: Quickshell.iconPath(p.group.icon || "folder", true), data: p.group })
        else out.push({ id: id, kind: "app", title: root.labelName(p.entry.appId, p.entry.name), icon: pop.appIcon(p.entry.appId), data: p.entry })
      } else if (kind === "run") {
        var r = root.runningByKey[key]
        if (r) out.push({ id: id, kind: "app", title: root.labelName(r.appId, r.name), icon: pop.appIcon(r.appId), data: r })
      } else if (kind === "tile") {
        var t = card ? card.tileByKey[key] : null
        var w = t ? (t.windows ? t.windows[0] : t.win) : null
        if (w) out.push({ id: id, kind: "tile", title: w.title || w.appId || "Window", icon: pop.appIcon(w.appId || ""), data: t })
      } else if (kind === "folder") {
        var f = card ? card.rightRowRef.folderByKey[key] : null
        if (f) out.push({ id: id, kind: "folder", title: f.name || DockLabels.folderBaseName(f.path || ""), icon: Quickshell.iconPath(f.icon || "folder", true), data: f })
      } else if (kind === "drive") {
        var d = card ? card.rightRowRef.driveByKey[key] : null
        if (d) out.push({ id: id, kind: "drive", title: d.name || "Drive", icon: Quickshell.iconPath("drive-removable-media", true), data: d })
      } else if (kind === "button") {
        out.push({ id: id, kind: "omarchy", title: "Omarchy", icon: Quickshell.iconPath("view-app-grid", true), data: null })
      }
    }
    return out
  }

  function appIcon(appId) {
    if (root && root.appLibrary) {
      var s = DockModel.resolveAppIcon(root.appLibrary, root.appRows, appId)
      if (s) return s
    }
    return Quickshell.iconPath("application-x-executable", true)
  }

  // A cell's centre in dock-window x, for the menus and popups it opens.
  function cellX(item) { return pop.popupWindow ? pop.popupWindow.toDockWindow(item, item.width / 2, 0) : Qt.point(0, 0) }

  function activate(cell, item) {
    var at = pop.cellX(item)
    if (cell.kind === "app") root.activate(cell.data.appId)
    else if (cell.kind === "group") root.openAppGroup(cell.data, at.x, 0)
    else if (cell.kind === "folder") {
      if (cell.data.command) Quickshell.execDetached(["sh", "-c", cell.data.command])
      else root.openFolderStack(cell.data.path, cell.title, at.x)
    }
    else if (cell.kind === "drive") root.openFolderStack(cell.data.mountpoint, cell.title, at.x)
    else if (cell.kind === "tile") root.restoreWindowBatch(cell.data.windows ? cell.data.windows : [cell.data.win])
    else if (cell.kind === "omarchy") Quickshell.execDetached(["omarchy-menu", "toggle", "root"])
  }

  function menu(cell, item) {
    var at = pop.cellX(item)
    if (cell.kind === "app") root.openContext(cell.data.appId, at.x, at.y)
    else if (cell.kind === "group") root.openAppGroupContext(cell.data, at.x, at.y)
    else if (cell.kind === "folder") root.openFolderContext(cell.data.path || "", cell.title, at.x, at.y, cell.data.command || "")
    else if (cell.kind === "drive") root.openDriveContext(cell.data.dev, cell.data.mountpoint, cell.title, cell.data.space || "", at.x, at.y)
    else if (cell.kind === "tile") root.openTileContext(cell.data.windows ? cell.data.windows : [cell.data.win], (cell.data.win || cell.data.windows[0]).appId || "", at.x)
    else if (cell.kind === "omarchy") root.openDockSettingsMenu(at.x, at.y)
  }

  z: 100
  color: Color.menu.background
  borderSpec: Border.surfaceSpec("menu", "border", Color.menu.border, 1)
  radius: Style.cornerRadius
  padding: Style.space(6)

  readonly property int cols: Math.min(5, Math.max(2, Math.ceil(Math.sqrt(cells.length))))
  readonly property real cellWidth: Style.space(64)
  readonly property real cellHeight: Style.space(70)
  width: cells.length > 0 ? grid.width + contentLeftInset + contentRightInset + Style.space(12) : 0
  height: cells.length > 0 ? grid.height + contentTopInset + contentBottomInset + Style.space(12) : 0

  Grid {
    id: grid
    columns: pop.cols
    spacing: Style.space(6)
    x: pop.contentLeftInset + Style.space(6)
    y: pop.contentTopInset + Style.space(6)

    Repeater {
      model: pop.cells
      delegate: Item {
        id: cellItem
        required property var modelData
        width: pop.cellWidth
        height: pop.cellHeight
        readonly property var appEntry: (modelData.kind === "app" && root) ? root.entryForId(modelData.data.appId) : null
        readonly property var wins: appEntry ? (appEntry.windowList || []) : []

        Rectangle {
          anchors.fill: parent
          radius: Style.cornerRadius
          color: cellArea.containsMouse ? Util.alpha(Color.menu.text, 0.08) : "transparent"
        }
        Column {
          anchors.centerIn: parent
          spacing: Style.space(4)
          width: parent.width - Style.space(8)
          DockIconArt {
            anchors.horizontalCenter: parent.horizontalCenter
            width: Style.space(36)
            height: Style.space(36)
            source: cellItem.modelData.icon
            renderSize: Style.space(36)
            iconStyle: root ? root.iconStyle : "original"
            tint: root ? root.tintFor(root.iconTint, Color.menu.text, Color.menu.background) : Color.menu.text
            grid: root ? root.iconGrid : 16
            outputScale: root ? root.outputScale : 1
            contrast: root ? root.iconContrast : 0
            strength: root ? root.iconStrength : 1
            hovered: cellArea.containsMouse
            hoverFx: root ? root.hoverFx : null
          }
          Text {
            width: parent.width
            text: cellItem.modelData.title
            textFormat: Text.PlainText
            color: Color.menu.text
            font.family: Style.font.family
            font.pixelSize: Math.max(9, Style.font.caption - 1)
            horizontalAlignment: Text.AlignHCenter
            elide: Text.ElideRight
            maximumLineCount: 1
          }
          Row {
            anchors.horizontalCenter: parent.horizontalCenter
            spacing: Style.space(3)
            visible: cellItem.wins.length > 0
            Repeater {
              model: Math.min(3, cellItem.wins.length)
              delegate: DockIndicator {
                required property int index
                rootRef: pop.root
                kind: (cellItem.wins[index] && root && cellItem.wins[index].address === root.activeWindowAddress) ? "active" : "window"
              }
            }
          }
        }
        MouseArea {
          id: cellArea
          anchors.fill: parent
          hoverEnabled: true
          acceptedButtons: Qt.LeftButton | Qt.RightButton

            if (!root) return

            // (closing destroys this cell; see the group right-click fix).

            var item = cellItem

            else pop.activate(cell, item)
          }
        }
      }
    }
  }
}
